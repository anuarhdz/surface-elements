# Lock page scroll by hiding root overflow

While a drawer is modal, `lockScroll()` sets `overflow: hidden` on `<html>`. It used to set it on `<body>` too, but that turns `<body>` into a scroll container and unsticks every `position: sticky` element on a scrolled page, and the Safari versions that needed it are below the Baseline target. Platform guidance prefers `overscroll-behavior: contain` on the dialog and its `::backdrop` and warns against touching root overflow, but Safari does not honour `overscroll-behavior` on non-scrollable containers, so the page behind still scrolls there; that was not acceptable. The CSS containment is kept as well, and `no-scroll-lock` drops it too, since containment alone already stops wheel and touch scroll from reaching the page. To limit the known costs, the lock reserves the scrollbar gutter (`scrollbar-gutter: stable`) when a classic scrollbar is present, is ref-counted across stacked dialogs, restores the inline values it found, and can be turned off per dialog (`no-scroll-lock`, `{ lockScroll: false }`).
