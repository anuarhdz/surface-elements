  </Card>
  <Card title="Pick your level" icon="puzzle">
    Use the CSS alone, the functions, or the web component. Each level builds on the one before.
  </Card>
  <Card title="Accessible by default" icon="approve-check">

  </Card>
  <Card title="Yours to style" icon="setting">
    Styles live in `@layer surface-elements`. Any unlayered rule wins, and `--surface-drawer-*` properties cover the rest.
