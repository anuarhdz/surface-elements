---
title: Sticky header
description: A custom element for a page header that sticks to the top.
---

import { Aside } from "@astrojs/starlight/components"
import Demo from "../../../components/demo.astro"

```js
import "surface-elements/header-sticky"
```

```html
<header-sticky>
  <strong>Store</strong>
  <button commandfor="cart" command="show-modal">Cart</button>
</header-sticky>
```

<Aside type="caution" title="Early">
Today `<header-sticky>` only registers the element. It ships no styles and no behavior, so the sticking comes from your CSS. It reserves the name and gives you a stable hook while the behavior is built.
</Aside>

```css
header-sticky {
  position: sticky;
  top: 0;
  z-index: 1;
  display: flex;
  align-items: center;
  gap: 0.75rem;
  background: Canvas;
}
```
