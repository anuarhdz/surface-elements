# AGENTS.md

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Component docs

Every web component page follows `docs/component-docs.md`. Naming rules are in `docs/adr/0003-surface-prefix-and-tag-naming.md`; vocabulary in `GLOSSARY.md`.

### Playground

Bare test pages per web component, without the docs layout, live in `demo/<component>/index.html` and are published at `/playground/<component>/` on the docs Worker and every PR preview. To add one, follow `docs/playground.md`.

### Library skill

`skills/surface-elements/` is the skill consumers' agents load to use this library. It is generated by `pnpm build` (`pnpm skills`) from the JSDoc in `src/` (via the Custom Elements Manifest), the docs pages in `site/src/content/docs/` and `scripts/skill-template.md`. Never edit it by hand: change the source, rebuild and commit the result. CI fails if it is stale. Document new elements with `@tag`, `@attr`, `@slot`, `@cssstate`, `@cssprop` and `@fires`.

### Copy files

`copy/surface-<name>.js` is one ES module per web component with every dependency inlined, for people who paste it instead of installing. `pnpm build` (`pnpm copies`, `scripts/emit-copies.ts`) writes one for every custom element in the manifest. Never edit them by hand; CI fails if they are stale. State shared between modules goes on a `Symbol.for("surface-elements.<name>")` global so copies and the package share it.

## Browser support

**Browser Support:** Baseline Newly available. Such features may be used when feature-detected, with a lightweight fallback where the library depends on them. No polyfills ship in the bundle; document the ones consumers may load. Deliberate deviations from platform guidance are recorded in `docs/adr/`.
