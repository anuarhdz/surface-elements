# surface-elements

Vanilla web components for common interface surfaces.

## Install

```bash
pnpm add surface-elements
```

## Usage

```js
// all elements
import "surface-elements"

// or one at a time
import "surface-elements/header-sticky"
import "surface-elements/dialog-drawer"
```

```html
<header-sticky>...</header-sticky> <dialog-drawer>...</dialog-drawer>
```

## Develop

```bash
pnpm install
pnpm dev      # demo at demo/
pnpm test
pnpm build
```
